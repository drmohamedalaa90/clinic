PUBLIC BOOKING — LOCATION SECTION
=================================

I need the exact Google Maps link/address from you before filling this with a real
clinic location. Do NOT publish an invented location.

In book.html, add this near your other top JavaScript constants:

const CLINIC_LOCATION = {
  mapsUrl: "",
  addressAr: "",
  directionsAr: [
    // Example after you send the real details:
    // "الدخول من ...",
    // "العيادة في الدور ...",
    // "أقرب علامة مميزة ..."
  ]
};

Then, in the SUCCESS summary, immediately after bookingSummary, add:

<div
  id="clinicLocationSummary"
  class="clinic-location-summary"
  style="display:none;"
></div>

Then, immediately after you build bookingSummary.innerHTML, add:

const locationBox =
  document.getElementById(
    'clinicLocationSummary'
  );

if(
  CLINIC_LOCATION.mapsUrl
  ||
  CLINIC_LOCATION.addressAr
  ||
  CLINIC_LOCATION.directionsAr.length
){
  locationBox.style.display = 'grid';

  locationBox.innerHTML = `
    <div class="clinic-location-heading">
      <span>📍</span>
      <div>
        <strong>مكان العيادة</strong>
        ${
          CLINIC_LOCATION.addressAr
            ? `<small>${escapeHtml(CLINIC_LOCATION.addressAr)}</small>`
            : ''
        }
      </div>
    </div>

    ${
      CLINIC_LOCATION.directionsAr.length
        ? `
          <div class="clinic-directions">
            <strong>كيفية الوصول إلى العيادة</strong>
            <ol>
              ${CLINIC_LOCATION.directionsAr.map(step=>
                `<li>${escapeHtml(step)}</li>`
              ).join('')}
            </ol>
          </div>
        `
        : ''
    }

    ${
      CLINIC_LOCATION.mapsUrl
        ? `
          <a
            class="clinic-maps-button"
            href="${escapeHtml(CLINIC_LOCATION.mapsUrl)}"
            target="_blank"
            rel="noopener noreferrer"
          >
            فتح الموقع على Google Maps
          </a>
        `
        : ''
    }
  `;
}
